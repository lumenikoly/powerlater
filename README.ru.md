# Таймер питания

Небольшое приложение на Rust для перевода компьютера в спящий режим или выключения через заданное время. Интерфейс построен на Slint, системные действия выполняются через API операционной системы.

## Возможности

- Интервал от 1 минуты до 24 часов.
- Быстрый выбор 15 минут, 30 минут, 1 часа или 2 часов.
- Русский и английский интерфейсы.
- Отмена после сна, длительной остановки цикла событий или существенного изменения системных часов.
- Безопасные режимы `--dry-run` и `--smoke-test`.

Таймер существует только внутри запущенного приложения. Закрытие окна, выход из системы, перезагрузка или сбой отменяют его.

## Сборка

```sh
cargo build --release
cargo test
cargo clippy --all-targets -- -D warnings
cargo run --release -- --lang ru
```

Исполняемый файл находится в `target/release/power-timer` (`power-timer.exe` в Windows).
